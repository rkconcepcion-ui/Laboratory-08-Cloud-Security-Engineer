# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. It is important in cloud computing because it reduces the risk of unauthorized access and limits the damage that can happen if an account is compromised.

## 2. Attack Surface

The attack surface refers to all the points where an attacker might try to access or exploit a virtual machine. These include open network ports, running services, and exposed applications, so reducing unnecessary access points helps improve server security.

## 3. Default Deny Policy

A Default Deny Policy blocks incoming network traffic unless a specific rule allows it. This is safer than trying to block individual attackers because unknown or unwanted connections are blocked by default, while only approved services can receive traffic.
